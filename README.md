# Coding-Solutions-0006
Simple Banking System

Write a program that:
• Starts with an initial balance of $500.
• Allows the user to Deposit, Withdraw, or Check Balance.
• Uses a switch-case for menu selection.
• Uses a do-while loop to continue transactions until the
user chooses to exit.
• Uses functions for deposit, withdrawal, and balance inquiry.
• Ensures the user cannot withdraw more than the available
balance (using an if condition).

Example:
Input: Option: Check Balance
Output: Balance: $500

Input: Option: Withdraw
$600
Output: Output: Insufficient
Funds
